How to Join

  1. Install tModLoader (free on Steam if you own Terraria), or click Launch tModLoader above.
  2. Open Workshop → Mod Browser and enable the server mods (or let the server download them automatically when joining).
  3. Keep tModLoader up to date on Steam so your client matches the server version.
  4. In the main menu, select Multiplayer → Join via IP: enter play.ronlab.site, port 7777 and the password.

          Chat Commands

          /ping
          Your round-trip latency to the server (visible only to you).
          /playing
          List players currently online.
          /roll
          Rolls a random number from 1 to 100.
          /p text
          Team-only chat message.

          Ping under ~80 ms is optimal, up to ~150 ms is playable. If world tick rate drops below 60/s, lag is server-side.
